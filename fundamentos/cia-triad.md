# 🔐 Tríade CIA

A Tríade CIA é um dos fundamentos da Segurança da Informação.

## Confidencialidade

Garante que somente pessoas autorizadas tenham acesso às informações.

**Exemplo:** impedir que uma pessoa não autorizada veja os dados de clientes.

## Integridade

Garante que as informações não sejam alteradas indevidamente.

**Exemplo:** impedir que um atacante modifique os dados de um sistema.

## Disponibilidade

Garante que sistemas e informações estejam disponíveis quando necessários.

**Exemplo:** manter um servidor funcionando para que os usuários consigam acessar o sistema.

## Resumo

| Princípio | Objetivo |
|---|---|
| Confidencialidade | Proteger o acesso aos dados |
| Integridade | Proteger contra alterações indevidas |
| Disponibilidade | Manter sistemas disponíveis |
