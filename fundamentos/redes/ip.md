# 🌐 Endereços IP

Um endereço IP identifica um dispositivo dentro de uma rede.

## Exemplo

192.168.1.25

## IPv4

Um endereço IPv4 possui quatro partes separadas por pontos.

Exemplo:

192.168.1.25

Cada parte possui um valor entre 0 e 255.

## IP e portas

Um IP identifica o dispositivo, enquanto uma porta identifica um ponto de comunicação associado a um serviço.

Exemplo:

192.168.1.25:443

- `192.168.1.25` → endereço IP
- `443` → porta
- HTTPS → serviço normalmente associado à porta 443

## Segurança

Conhecer os endereços e serviços de uma rede é importante para entender sua superfície de ataque.

Testes de segurança devem ser realizados somente em redes próprias ou com autorização.
