# 🌐 DNS

DNS significa Domain Name System.

Ele é responsável por traduzir nomes de domínio em endereços IP.

## Exemplo

Quando acessamos:

`google.com`

O DNS ajuda o dispositivo a descobrir o endereço IP associado ao domínio.

## Exemplo simplificado

`google.com` → `IP do servidor`

Assim, não precisamos decorar endereços IP para acessar sites.

## Porta

O DNS utiliza principalmente:

- `53/udp` → consultas DNS comuns
- `53/tcp` → também pode ser utilizado em determinadas situações

## Por que DNS é importante em Cibersegurança?

O DNS faz parte da infraestrutura de rede e pode fornecer informações importantes sobre como os sistemas se comunicam.

Durante uma análise autorizada, podemos observar:

- Domínios
- Endereços IP
- Servidores DNS
- Consultas DNS
- Registros DNS

## Segurança

Problemas relacionados ao DNS podem afetar a disponibilidade, confidencialidade ou integridade das comunicações.

Por isso, entender DNS é importante para estudar redes e segurança da informação.

> Análises e testes devem ser realizados somente em sistemas próprios ou autorizados.
