# 🔐 Laboratório de Cibersegurança

Laboratório pessoal de estudos práticos em Cibersegurança,
Segurança da Informação, Redes, Linux, Nmap e Ethical Hacking.

## 📚 Conteúdos estudados

- Fundamentos de Cibersegurança
- Tríade CIA
- Vulnerabilidades, ameaças e riscos
- Redes de computadores
- IP, TCP e UDP
- Portas e serviços
- DNS
- Nmap
- Linux
- Segurança Web
- Ethical Hacking em ambientes autorizados

## 🎯 Objetivo

Desenvolver conhecimentos práticos em segurança da informação
através de estudos, exercícios e laboratórios controlados.

## ⚠️ Ética

Todos os testes de segurança realizados neste projeto devem
ocorrer somente em sistemas próprios, ambientes de laboratório
ou sistemas para os quais exista autorização.
